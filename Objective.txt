Objective
Create a shopping cart page using a StatelessWidget. Replicate the generated reference image above, focusing on nested layouts, reusable widgets, consistent styling, and button callbacks.

Instructions
Create a Flutter project named stateless_lab_exam.
Inside lib/, create shopping_cart_page.dart.
Implement a StatelessWidget named ShoppingCartPage.
Configure main.dart to display this page.
Use Flutter widgets to build every section. Do not use the reference image as the application’s interface or background.

Layout and Styling Requirements
Follow the reference image’s section order, colors, alignment, and visual hierarchy.
Use a light-gray page background, white cards, and blue accents.
Apply consistent padding, spacing, and rounded corners.
Use Row, Column, Expanded or Flexible, and Stack appropriately.
Make the page vertically scrollable so all sections remain accessible on smaller screens.
Avoid overflow errors.
Use standard Flutter widgets without third-party UI packages. Similar Material icons are acceptable.
